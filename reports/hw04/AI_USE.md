## 2. One AI-produced output that was wrong or unsuitable, or one thing independently verified

Several generated assumptions were checked rather than accepted. In Part 1, generated controls used unstable accessible-name associations, and a browser test tried to read a 204 response body after navigation. Actual Playwright runs failed. In Part 2, generated database tests expected all rejected rental values to raise `IntegrityError`; PyMySQL exposed CHECK error 3819 as `OperationalError`, causing four test failures even though MySQL correctly rejected the data. In Part 3, the initial seed CLI committed database inserts before opening its evidence file, so a bad output path could leave rows without a seed manifest. Review and a regression test exposed that ordering problem.

The N+1 behavior was also independently checked against executed SQL. An ORM identity map can reuse a manager already loaded in the session, so code that appears to fetch a manager per rental may issue fewer statements than expected. The experiment needed to prove its actual SQL counts, including shared authentication work.
